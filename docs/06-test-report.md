## 7. 已知限制

以下是设计上的取舍，不是缺陷，已写入 README 的“已知限制”或本文档：

- 扫描版 PDF 不做 OCR，只能基于摘要回答。
- 看板的“活跃论文”按每篇论文最后一次阅读的日期计数，连续几天阅读同一篇论文只算在最后一天。
- 问答中途停止时不保存这一轮对话；多论文对比不保存记录。
- SQLite 只适合单机部署。

## 9. 结论

核心流程（上传、解析、阅读、问答、导读、笔记、复习）和全部 AI 功能在真实模型下工作正常，用户隔离和权限控制符合设计，Docker 部署可以正常构建、运行并保存数据。遗留问题是注册页提示文字与实际规则不一致（D-10），以及 Semantic Scholar 检索受外部限流影响未能验证。
