* CBaldur 前端（cbaldur-frontend）

** 项目简介
CBaldur 前端基于 Nuxt3 + TypeScript + Tailwind CSS，提供案例管理、仿真任务、数据可视化、用户与组织管理等交互界面。支持多端适配、现代组件化开发、与后端 RESTful API 对接。

** 技术栈
- Nuxt3 (Vue3)
- TypeScript
- Tailwind CSS
- Nuxt UI、antv/g2、d3、monaco-editor、markdown-it

** 主要功能
- 用户注册、登录、GitHub OAuth、个人信息与头像管理
- 案例的创建、编辑、运行、文件管理、在线编辑与执行
- 组织、公告、通知管理
- 数据可视化（等高线、线图、Gfile等）
- 案例分享与对比

** 运行方式
1. 安装 Node.js >= 16
2. 复制环境变量模板
   #+begin_src bash
   cp .env.example .env
   #+end_src
3. 安装依赖
   #+begin_src bash
   yarn           # 或 npm install / pnpm install / cnpm install
   #+end_src
4. 启动开发环境
   #+begin_src bash
   yarn dev       # 或 npm run dev / pnpm dev / cnpm run dev
   #+end_src
5. 构建生产包
   #+begin_src bash
   yarn build     # 或 npm run build / pnpm build / cnpm run build
   #+end_src

** 目录结构
- pages/        页面与路由
- components/   组件
- composables/  组合式函数
- layouts/      布局
- middleware/   中间件
- public/       静态资源

** 配置说明
- .env：前端环境变量（后端API地址等）
- nuxt.config.ts：Nuxt 配置

** 依赖
- Node.js >= 16
- 推荐包管理器 yarn/npm/pnpm
